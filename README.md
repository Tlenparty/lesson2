# Array Exercises

Набор небольших упражнений с массивами на Java (`com.tlenparty.arrays.MainApp`):

1. Инверсия массива из 0 и 1.
2. Заполнение массива значениями 0, 3, 6 … 21.
3. Умножение на 2 всех элементов меньше 6.
4. Заполнение обеих диагоналей квадратной матрицы единицами.
5. Поиск минимального и максимального элемента.
6. `checkBalance` — есть ли в массиве место, где сумма левой и правой частей равна.
7. `move` — циклический сдвиг массива на *n* позиций (в обе стороны) без вспомогательного массива.

## Запуск

Требуется JDK 8+.

```bash
javac -d out src/main/java/com/tlenparty/arrays/MainApp.java
java -cp out com.tlenparty.arrays.MainApp
```
