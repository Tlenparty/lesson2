# Array Exercises

A set of small array exercises in Java (`com.tlenparty.arrays.MainApp`):

1. Inverting an array of 0s and 1s.
2. Filling an array with the values 0, 3, 6 ... 21.
3. Multiplying by 2 all elements less than 6.
4. Filling both diagonals of a square matrix with ones.
5. Finding the minimum and maximum elements.
6. `checkBalance`: whether the array has a position where the sums of the left and right parts are equal.
7. `move`: cyclic shift of an array by *n* positions (in either direction) without an auxiliary array.

## Run

Requires JDK 8+.

```bash
javac -d out src/main/java/com/tlenparty/arrays/MainApp.java
java -cp out com.tlenparty.arrays.MainApp
```
